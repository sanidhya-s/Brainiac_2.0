# Brainiac 2.0 (BI Copilot) 🚀

This is a complete, production-ready Full-Stack Next.js application that serves as an "AI-Powered Business Intelligence Copilot". It allows non-technical users to upload raw data (Excel/CSV), ask natural language questions, and instantly receive custom, interactive charts and insights generated by the Google Gemini API.

The UI layout is an exact 1:1 match of the **Lumina Intelligence** design system (from Google Stitch).

## Features
- **Generative UI Architecture**: Completely dynamic components that render based on the dataset schema and user prompt.
- **Lumina Design System**: High information density, modern Emerald styling with Tailwind CSS.
- **Serverless API**: Secured Gemini integration inside a Next.js API Route (`/api/chat`).
- **Instant Data Parsing**: Full frontend parsing of XLSX and CSV using `xlsx`.

## Instructions for Running Locally

### 1. Install Dependencies
Make sure you have Node.js installed, then run:
```bash
npm install
```

### 2. Set Up Environment Variables
Create a `.env.local` file in the root directory (or rename `.env.example` if it exists) and add your Google Gemini API Key:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Run the Development Server
```bash
npm run dev
```

The application will now be running on [http://localhost:3000](http://localhost:3000).

## Hosting on Vercel

This repository is optimized for deployment on Vercel. 
1. Push this repository to GitHub.
2. Log into [Vercel](https://vercel.com/) and create a new project.
3. Import your GitHub repository.
4. **Important**: In the Environment Variables section during setup, add `GEMINI_API_KEY` and your actual key.
5. Deploy!

*(Live Demo: [https://bi-copilot-pi.vercel.app](https://bi-copilot-pi.vercel.app))*
